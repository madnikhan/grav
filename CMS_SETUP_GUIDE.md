## 🚀 **HOW TO USE THE CMS**

### **1. Access Admin Panel**
1. Go to: `http://localhost:8000/admin`
2. Login with your credentials
3. You'll see the dashboard

### **2. Edit Pages**
1. Click "Pages" in the sidebar
2. Find the page you want to edit
3. Click "Edit" button
4. Use the editor to modify content
5. Save changes

### **3. Upload Media**
1. Go to "Media" in the sidebar
2. Click "Upload" button
3. Select images/files
4. Organize in folders
5. Use in your pages

### **4. Create New Pages**
1. Click "Add Page" button
2. Choose page template
3. Fill in content
4. Set page settings
5. Publish

### **5. Manage Products**
1. Edit `/user/pages/03.products/default.md`
2. Update product information
3. Add new products
4. Modify prices and descriptions
